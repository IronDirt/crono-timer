# SEO Strategy - CronoTimer

## Meta Tags
- **Title**: CronoTimer - Modern Online Stopwatch and Timer
- **Description**: A clean and simple online stopwatch and countdown timer with dark/light mode and fullscreen capabilities.
- **Keywords**: stopwatch, timer, online timer, countdown, lap timer, cronotimer, beautiful timer.

## Semantic HTML
- Use `<h1>` for the primary page title.
- Use `<time>` element for displaying time.
- Use `<button>` elements for interactive controls.
- Use `aria-label` for buttons that only have icons.

## Performance
- Font: Use Google Fonts `Inter` with `font-display: swap`.
- Images: Pre-optimize any imagery to WebP.
- Assets: Minify CSS and JS before production.
