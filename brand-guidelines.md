# Brand Guidelines - CronoTimer

## Color Palette

### Light Mode
- **Background**: `#FFFFFF`
- **Surface**: `#F5F5F7`
- **Text (Primary)**: `#1D1D1F`
- **Text (Secondary)**: `#86868B`
- **Accent**: `#0071E3` (Apple Blue)
- **Danger**: `#FF3B30`

### Dark Mode
- **Background**: `#000000`
- **Surface**: `#1D1D1F`
- **Text (Primary)**: `#F5F5F7`
- **Text (Secondary)**: `#86868B`
- **Accent**: `#0A84FF`
- **Danger**: `#FF453A`

## Typography
- **Primary Font**: `Inter`, system-ui, -apple-system, sans-serif.
- **Size**:
    - **H1 (Large Display)**: 4rem (for the timer digits)
    - **H2**: 2rem
    - **Body**: 1rem

## Styling Principles
- **Minimalism**: Clean lines, generous whitespace.
- **Glassmorphism**: Subtle backdrop blurs for overlay components if used.
- **Micro-animations**: Smooth transitions for theme switching and button hover.
- **Accessibility**: High contrast for readability.
